## Agentic 场景功能

- `scenes edit` 支持自然语言或结构化修改、外部资产目录、SceneStore revision、完整 TaskIntent 与 TaskProgram 更新。修改后的 bundle 保存来源版本、实际模型请求、修改内容与待检查项目。
- `scenes inspect --probe` 使用实际 GLB mesh 测量夹持尺寸、容器开口、内部区域与支撑范围。测量报告保存资产、尺度、collision、机器人文件与程序 SHA256。物理抓取与任务成功单独验收。
- `scenes generate --capability-probes` 将能力检查加入生成流程，几何要求未通过时进入现有修改循环。缺少检查的 required_capabilities 保留明确的待检查记录。
- `scenes read-bddl` 使用官方 bddl 3.6.0 读取完整对象、初始条件与量词目标，支持 inside、ontop 的明确场景绑定和 bundle 导出。原始初始条件与容器物理证据保留待验收状态。
- `scenes calibrate-video` 读取实际 MP4、拟合点和独立验证点，使用 OpenCV PnP 标定。`scenes metric-layout` 检查视频与标定来源，根据物体中心的已知高度恢复位置并保存来源报告。真实视频恢复尚需实际测量与场景验证。
- `scenes preview` 生成包含真实资产与官方 SO-101 mesh 的交互式 HTML 预览。

实际模型完成三次连续布局修改，检查保存全部请求与版本。官方 SO-101 MJCF 与 Apple bundle 的交互式预览包含 19 个 mesh 节点。最新 CPU 检查通过 49 项，包含场景版本、任务条件保存、实际 mesh、MuJoCo 六物体量词目标、实际 CPU renderer MP4 标定、USD 文件组合与导入，以及 GPU 执行前的源码、报告与进程停止检查。容器内部、杯壁、底部和 convex hull 的实体包含检查使用实际 mesh。

CPU OSMesa 渲染生成真实 MP4，八个点用于相机标定，四个独立点用于位置恢复。独立点的最大位置误差为 0.82 mm。该结果属于模拟视频的米制位置恢复。真实用户视频与实际物体测量继续单独验收。
