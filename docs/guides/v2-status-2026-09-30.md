# v2 开发状态 · 2026-09-30

本轮迭代补齐了 CPU/数据边界的遗留问题，并把仓库文档中引用但缺失的安装入口补上。

已完成：

- LeRobot 本地数据加载不再因 `num_frames` 存在而错误调用 `len(dataset)`；本地文件路径会在导入 LeRobot 前给出明确错误。
- HDF5 episode 校验覆盖动作、本体状态、时间戳、相机形状、有限值、FPS 和可选仿真状态长度；录制器在写入前检查帧形状、相机尺寸、时间戳和 checkpoint 范围。
- OpenAI-compatible 场景模型服务支持无鉴权服务、完整 endpoint URL 和对象形式的 JSON 响应，并对异常响应给出明确错误；Responses wire 对齐 Codex 的 developer/user input、SSE、reasoning 和有限重试。
- 场景资产 bounds、任务状态 quaternion、版本存储输入和 bundle manifest 校验更加严格，并兼容旧版场景 hash。
- 新增不依赖 Isaac Sim 的静态场景诊断：初始 AABB 碰撞、`inside` 容器空间和 `on_top` 支撑面尺寸；新增确定性 reset 采样工具。
- 新增 real2sim agent loop：RGB 视频采样帧进入 GPT-6 Astra，多阶段结构化输出驱动 Objaverse/LVIS 检索、场景编排、缺失 primitive 资产生成、静态物理检查、GPT 物理合理性审查和 SO-101 数据采集 readiness 审查；支持注入 Isaac runtime checks。
- OpenAI-compatible 模型客户端支持多模态 `image_url` 帧消息；新增 `scenes agent-loop` CLI，默认模型名为 `gpt-6-astra`，可自动读取 LitchiAgent Codex runtime 配置，并支持离线 Objaverse 回退和可调 reasoning/帧数。
- 新增 PyAV 视频自动抽帧、时间戳和 SHA256 记录；Astra 场景失败后支持最多两轮结构化修复；generated parts 使用声明式 primitive recipe 并保留材质/来源 metadata。
- CPU pytest 可用 `OPENSO101_SKIP_ISAAC=1` 跳过 Omniverse 启动；runtime worker 在未生成报告时给出明确错误。
- 新增 `environment.yml`、`scripts/install.sh`、`scripts/fetch_so101_usd.sh`、CUDA/构建约束文件和安装、快速开始、遥操作、自定义任务指南。

本轮回归结果：8 个 CPU agent/data 回归测试通过，额外 26 个 scene CPU 测试通过；旧 Apple bundle、已编译运行目录、1 个 Apple 场景和 5 个 RoboTwin bundle 均可读取/校验，静态诊断全部通过；安装脚本通过 shell 语法检查，wheel 构建通过。
