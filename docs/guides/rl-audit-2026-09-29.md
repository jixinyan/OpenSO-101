# RL 配置、reward 与抓取动作检查

## 训练配置

本次实际运行使用统一 RSL PPO 入口，参数保存在 [Lift train.json](../validation/2026-09-29/lift_seed42/train.json) 和 [PickPlace train.json](../validation/2026-09-29/pick_place_seed42/train.json)。

| 参数 | 实际数值 | 判断 |
|---|---|---|
| 训练环境 | 1024 | 每次更新有充足的并行样本 |
| rollout | 96 步 | 每次更新 98,304 transitions |
| epochs / minibatches | 5 / 4 | 可作为 PPO 实验基准 |
| learning rate | 0.0001 | 未观察到数值异常，收敛效率仍需实验 |
| hidden_dims | 256/128/64 | 当前状态观测对应的 MLP 可以作为实验基准 |
| 观测归一化 | 启用 | 已包含于导出模型，数值比较通过 |
| 初始探索标准差 | 0.5，log 参数化 | 训练保持有限值；夹爪动作的实际执行需要独立检查 |
| entropy coefficient | 0.005 | 当前数据不能单独判定其取值影响 |
| gamma | 0.99 | 50Hz 下有效折扣时间约 2 秒；400 步后的折扣系数约 0.018 |
| 总迭代次数 | 200 | 每项 19,660,800 transitions；尚未通过任务收敛验收 |

手臂动作含义为 `default_joint_position + 0.5 * action`，夹爪动作以正负符号选择 0rad 或 0.8rad。它需要在每个控制步骤重新判定开合。机器人关节速度限制为 2rad/s，夹爪从 0.8rad 移动至 0rad 至少需要约 0.4 秒。

训练包含机器人质量、关节参数、PD、物体质量与接触材质、重力及观测随机化。评估关闭观测与动作随机化，物理事件仍然存在。其对抓取学习的影响需要受控比较。配置中的 30Nm effort limit 与真机的实际驱动能力也需要通过硬件测量验证。

## 实际夹爪诊断

每项最终策略重新加载后，在四个 Isaac 环境执行 500 个控制步骤，同时记录关节状态、动作、实际双夹爪接触力和每项 reward。统计来自确定性策略。

| 指标 | Lift | PickPlace |
|---|---:|---:|
| 平均末端至物体距离 | 0.04365m | 0.03953m |
| 关闭夹爪指令比例 | 48% | 0% |
| 开合符号切换总次数 | 1250 | 0 |
| 双侧接触步骤比例 | 0.25% | 0% |

Lift 的频繁开合与夹爪达到关闭位置所需时间存在冲突，策略尚未形成连续保持抓取的行为。PickPlace 在这些状态中持续发送打开夹爪指令，抓取、抬升、搬运与释放奖励无法形成实际任务进度。一次四环境诊断只能说明这些记录中的行为；总体任务结果采用各自的 100-episode 独立评估，均为 0/100。

## Lift reward

接近奖励由两个 `1-tanh(distance/std)` 项组成，尺度为 0.20m 和 0.05m，权重均为 0.5。双侧接触奖励权重为 6；高度奖励权重为 3；高度条件下的目标距离奖励权重为 5；成功区域奖励权重为 3。

此次 2000 个环境控制步骤的接近奖励合计约 23.98，接触奖励合计 0.6，抬升奖励合计 0.06，目标距离奖励合计 0.053，成功区域奖励为 0。策略取得的 reward 主要来自接近物体。

高度奖励和 success termination 检查物体高度及目标距离，未检查持续抓取。完成定义需要反映抓住并保持物体的目标。抓取姿态、夹爪闭合时机和连续接触也需要可学习的阶段信号；单独提高接触奖励权重尚无证据保证跨越抓取阶段。

## PickPlace reward

接近 reward 使用距离变化，权重为 30；接触保持权重为 0.2；接触开始事件权重为 5；抓取期间的阶段目标距离变化权重为 12；释放后在目标稳定 0.5 秒的成功权重为 50。

Isaac RewardManager 将各项乘以 `control_dt=0.02`：接近 1mm 对应约 0.0006；一次接触开始事件对应 0.1；一次接触保持步骤对应 0.004；一次最终成功对应 1.0。这些量级必须结合出现频率、折扣和实际轨迹评估。

接近距离变化可以提供移动方向信号，但该标量未直接描述夹爪轴向、物体是否进入两侧夹爪之间以及闭合时机。双侧接触事件具有稀疏性。当前策略已经接近物体，尚未学会关闭夹爪。

搬运距离变化仅在保持抓取时启用。释放阶段的连续开合与脱离接触行为主要依赖最终稳定放置奖励，学习信号仍需验证。reset、抓取状态切换和目标阶段切换都设置了距离差分保护；完整实际阶段运行尚未通过。

`action_rate` 在 `common_step_counter > 48,000` 后调整为 `-0.0001`。本次仅执行 19,200 个控制步骤，其权重保持为 0。`joint_vel` 从训练开始启用，权重为 `-0.0001`。这些判断已核查安装环境中的 Isaac Lab 实现。
