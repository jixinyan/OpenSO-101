# v2 迭代顺序

## 键盘遥操作与数据流程

用户已授权新的 RL 训练，并要求保留全部模型与评估记录。当前同时检查 RL 的配置、reward 和实际控制，推进键盘遥操作、数据导出与回放、MuJoCo sim2sim 和 Agentic 场景。真机工作根据用户要求暂缓，定时任务已取消。

验收沿用 v2 Spec：Lift 与 PickPlace 在三个随机种子下达到规定的收敛指标，使用 100-episode 评估，连续三次评估成功率至少 90%。短程启动和模型文件读取保留独立检查状态。

已有 KeyboardDevice、Jacobian IK 与录制入口需要完成实际人工操作检查，保证移动、旋转、夹爪控制、关节限位、控制频率与双相机显示正常。使用键盘完成任务并保存成功 episode，验证 HDF5、本地 LeRobot 导出、全部帧读取和场景回放。使用指南保存实际通过的启动方式和按键说明。

## MuJoCo sim2sim

复用 Isaac Lab 训练并评估的策略，在 MuJoCo 中加载 SO-101 和对应任务。保持关节顺序、坐标、单位、观测构成、归一化、动作含义及控制周期一致，记录驱动参数、关节限位、物体质量、摩擦和碰撞配置。

使用相同策略和可复现的任务初始条件执行 MuJoCo 评估。记录两种模拟器的成功率、轨迹、接触行为和失败原因，验证策略推理、控制与任务完成。已有 `rl export` 与 `sim2sim mujoco` 入口，两项策略各完成四个配对场景运行；接触动力学比较和成功策略迁移仍需验收。接口说明见 [sim2sim](sim2sim.md)。

## sim2real

维护 SO-101 校准、关节映射、相机配置、控制周期、动作限幅与停止控制的已有入口。策略部署复用已验证的模型、观测处理和动作转换，保存运行配置及模型版本。

已有 `sim2real validate` 入口检查实际录制数据上的视觉 student 推理与共享动作转换。新 student 接收双相机、关节位置与 robot root frame 的任务目标。独立任务评估使用 `rl student-eval`，真机验收保持待执行状态。

## Agentic real2sim

Agentic 场景工作流保持同步推进，维护已有文本与视频入口、资产管理、场景生成及审查功能。其运行验收单独安排，保留生成场景、检查报告及数据之间的版本关系。当前主要验证资源用于键盘遥操作、数据流程、sim2sim 和 sim2real。

当前功能和验证记录见 [v2 状态](v2-status-2026-10-03.md)，训练入口见 [训练与蒸馏](v2-training.md)，采集入口见 [遥操作](teleop.md) 和 [自定义场景](custom-scenes.md)。
