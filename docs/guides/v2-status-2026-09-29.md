## P6 当前行为

`scenes generate` 接收文本指令与已有资产目录，调用模型生成 SceneSpec，并检查配置、桌面范围和静态几何，保存 proposal。

`scenes agent-loop` 使用 PyAV 从 MP4 抽取图像及时间戳，记录源文件 SHA256，再执行 Astra 视频描述、资产查询、场景编排、Trimesh primitive/generated parts 生成、静态诊断、物理合理性审查和 SO-101 readiness 审查。配置支持 OpenAI-compatible Chat Completions 与 Responses，并可读取指定 Codex TOML。用户任务指令保存在场景中；默认最多执行两轮场景修复。

资产查询检查本地目录的名称与来源，再查询 Objaverse LVIS 类别。生成物体使用 box、cylinder、sphere 及其组合，保留 recipe、来源与材质信息。视频结果包含物体描述和估计尺寸、位置；度量重建与任务接触几何需要独立测量和验证。

Real2SimAgentLoop 提供 `physics_runtime_check` 和 `so101_runtime_check` 注入接口。当前 CLI 没有连接这两个接口，也没有自动执行 USD 编译、Isaac 运行检查或数据采集。`status=completed` 的条件是静态诊断与两项模型审查通过，仍需读取 `pending_checks` 并执行相应运行验收。

Spec 要求的 TaskIntent、TaskProgram、资产 embedding 与能力索引、预算控制、按 scene_id 执行自然语言修改，以及从任务输入到成功数据集的全部状态转换，仍需要继续完成和验收。当前 SceneSpec、Task 与版本存储承担已有配置和修改功能。
