## 恢复运行所需环境

Isaac Sim 5.1.0、Isaac Lab 2.3.0、Python 3.11.16、Torch 2.7.0 + cu128。目标 GPU 报告为 NVIDIA H20G，CUDA capability 为 `sm_103`，使用 `requirements-sm103.txt` 中的 NVRTC 12.9.86。

```bash
export OMNI_KIT_ACCEPT_EULA=YES
export OPENSO101_SO101_USD_PATH="$PWD/outputs/SO-ARM101-USD.usd"
export TMPDIR="$PWD/outputs/tmp"
export LD_LIBRARY_PATH="/home/jixin/workspace/envs/openso101-v2/lib/python3.11/site-packages/nvidia/cuda_nvrtc/lib:/home/jixin/workspace/envs/edh-graphics/root/usr/lib/x86_64-linux-gnu"
```

LeRobot 视频读取使用 `outputs/ffmpeg/root/usr/lib/x86_64-linux-gnu` 中的 FFmpeg 及运行依赖。`LD_LIBRARY_PATH` 包含该目录及其 `pulseaudio`、`blas`、`lapack` 子目录，并保留上述 graphics 目录。`PATH` 包含 `outputs/ffmpeg/root/usr/bin`。相关软件包保存在同一目录中。远程 `outputs/read_dataset.sh` 保存了本次实际通过的读取命令。

使用方法参见 [自定义场景](custom-scenes.md) 和 [v2 训练](v2-training.md)。
